# gcore_cloud_k8s_cluster_kubeconfig (Data Source)

Kubeconfig provides the necessary configuration and credentials to access a Kubernetes cluster using kubectl or other Kubernetes clients.

~> **Credential-bearing data source**
`config`, `client_key`, `client_certificate`, and `cluster_ca_certificate` are marked sensitive, so Terraform redacts them in plan and apply output. Sensitivity affects display only: the values are still written to Terraform state in plaintext, and referencing them in an output requires `sensitive = true`. Store state in an encrypted remote backend and restrict access to it as you would to the kubeconfig itself.
